# KitchenPulse 🍴

Application de gestion de restaurant en temps réel intégrant les rôles
Client, Cuisinier, Serveur et Administrateur.

## Stack technique

- **Backend** : Node.js · Express 5 · MySQL 2 · Socket.io · JWT
- **Frontend** : React 18 · Vite · Tailwind CSS · Axios · react-toastify
- **Base de données** : MySQL / MariaDB (`kitchenpulse_db`)
